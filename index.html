A lightweight static website packaged into a Docker image and served by Nginx. Built locally to practice image creation, container execution, port mapping, and safer container defaults.

$ http://localhost:8080

What this project demonstrates
01 — BUILD

Custom image

Use a Dockerfile to package the static webpage and Nginx configuration into a repeatable image.

02 — RUN

Container lifecycle

Start the container in detached mode, inspect its status, and verify the service through logs and health checks.

03 — SERVE

Port mapping

Publish container port 8080 to the local machine so the webpage is accessible in a browser.
